# 보존할 게임 기획, 재사용하지 않을 구현

## 목표

AFFIX: ZERO는 Hero Siege식 장비 파밍/어픽스/빌드와 Survivor.io식 읽기 쉬운 다수 적 전투/선택형 성장을 결합하는 캐주얼 핵앤슬래시 로그라이크 방치형 게임이다. 이 내용은 사용자의 기획이지 두 게임 소스코드 복제 지시가 아니다.

기본 루프는 자동사냥 -> 처치/보상 -> 장비·스킬 선택 -> 달라진 전투 -> 다음 구간이다. 첫 MVP에서는 전사 1종으로 좁힌다. 나머지 직업, 장비 슬롯, 가방 용량 등 과거 수치는 새 구현의 완료사항으로 취급하지 않는다.

## 첫 플레이 빌드 U1

밝은 작은 야외 필드 1개, 검수한 캐릭터 1종과 근접 적 1종, 실제 idle/walk/attack/hit/death 동작, 타격 프레임과 피해 일치, 경험치/골드 획득, 짧은 전투 반복. 검을 캐릭터와 따로 떠다니게 하지 않는다. UI는 체력/획득/단계만 보여주고 진단값은 기본 게임 화면에서 숨긴다.

먼저 1대1의 실제 화면과 움직임을 완성하고, 다음 원거리 적/투사체, 소규모 웨이브, 임시 스킬 3지선다, 장비 비교/장착 순서로 확장한다. 자동 이동을 기본으로 하고 수동 개입 여부는 U1에서 별도 결정한다.

## 이후 콘텐츠

아이템 등급·어픽스, 능동 스킬과 시너지, 직업 확장, 장비 강화, 도감, 환생, 펫, 무료 재화 소환, 외형 아바타, 오프라인 보상, 래더/스탠다드 시즌과 시즌 외형 보상을 마스터 로드맵으로 유지한다. 첫 MVP에 한꺼번에 구현하지 않는다. 유료 가챠/결제/온라인 랭킹은 서버 검증과 운영 설계가 생긴 뒤 별도로 검토한다.

## 시각 방향

밝고 선명한 야외 모험과 캐주얼 탑다운 RPG. 기존 다크한 분위기와 기존 이미지 전부 폐기. 새 자산 후보는 Tiny Swords 제작자 제공 CC0 구버전이며 실제 ZIP/동봉 라이선스/프레임은 아직 미검수다. 라이선스가 확인된 다른 패키지도 검토할 수 있으나 여러 팩을 무작정 혼합하지 않는다.

새 구현에 옛 GDScript/.tres/저장 구조를 가져오지 않는다. 기존 사용자 세이브는 로컬에서 그대로 두되 새 앱이 자동 로드/변환하지 않는다.
