# Hero Siege 오마주 아트 방향

2026-09-26 최신 사용자 지시가 유일한 기준이다. **탕탕특공대 요소는 폐기하고 Hero Siege의 PC UI/UX와 시각 밀도를 지향한다.** 사용자가 첨부한 던전 전투 화면을 직접 확인했다. 이전의 밝은 초원 고정·다크 던전 금지는 더 이상 적용하지 않는다. 옛 Godot 이미지/소스는 여전히 복원하지 않는다.

## 거절된 것

Ninja Adventure의 큰 머리 캐릭터·평평한 초원·장식 크기와 두 차례의 사각 정보판 HUD는 채택 철회다. 기존 에셋을 어둡게 틴트하거나 HUD 좌표만 옮겨 같은 결과를 반복하지 않는다. 기존 씬과 로컬 빌드는 거절된 기술 시제품이며 새 방향의 결과물이 아니다.

## 새 시각 기준

- 작은 캐릭터 주변에 이동 경로·적 접근·투사체·전리품을 읽을 수 있는 넓은 PC 가로 전장.
- 입체 높이가 느껴지는 벽·기둥·문, 변주된 석재 바닥, 소품·그림자·국소 광원으로 공간을 구성하는 픽셀 던전. 전체 화면에 어두운 필터를 씌우는 것으로 대체하지 않는다.
- 배경보다 명확한 캐릭터 실루엣과 고대비 공격/피격 효과. 원본의 서로 다른 걷기·공격·피격·사망 자세가 있어야 한다.
- 얇은 장식 프레임, 작은 초상/자원 바, 실제 아이콘 hotbar·쿨다운·키 표시, 실제 지형과 위치를 전달하는 미니맵. 문장형 AUTO ATTACK 패널은 목표가 아니다.
- 장비는 고정 수치 열람표가 아니라 드랍→소지→현재 장비와 비교→장착→전투 변화의 UX를 가진다. 아이콘·희귀도·어픽스·툴팁·슬롯이 이 흐름을 지원해야 한다.

## 반입 판단

무료 또는 CC0라는 이유만으로 화풍이 맞지 않는 팩을 선정하지 않는다. 캐릭터·환경·UI를 게임 내 크기로 함께 검토한다. 서로 다른 원본 pixel density·외곽선·시점·palette를 무작정 섞지 않는다. 후보의 제작자 페이지, 정확 파일/버전·해시·게임 사용·원본 공개 권리, 프레임/방향/pivot/impact를 기록한다.

유료 구매는 별도 사용자 동작/승인이 필요하다. 무료 사용 가능하더라도 raw asset 재배포 금지면 공개 GitHub에 올리지 않는다. 원작 Hero Siege의 이미지·지도·UI 조각·아이콘을 추출해 게임에 넣지 않는다. 라이선스가 있는 신규 리소스로 독자적인 화면을 구성한다.

검토 결과는 docs/assets/HERO_SIEGE_*_CANDIDATES.md, 기능 목표는 docs/HERO_SIEGE_UX_SPEC.md에 둔다. 새 아트 시제품의 실제 Unity 화면을 확인하기 전 채택 완료로 표시하지 않는다.
