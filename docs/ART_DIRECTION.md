# 새 아트 방향 v0.2

사용자 확정: 기존 이미지 전부 폐기. 어두운 폐허·붉은 균열·검고 칙칙한 화면을 이어가지 않는다. 새 방향은 밝고 선명한 야외 캐주얼 탑다운 RPG다.

첫 시각 기준은 낮의 초원·길·물, 분명한 캐릭터/적 실루엣, 몸과 무기가 함께 보이는 공격, 전투를 가리지 않는 간결한 HP/보상 UI다. UI는 밝은 종이/아이보리와 명확한 강조색을 제안한다. 팔레트 수치·해상도·픽셀 밀도는 실제 채택 팩을 확인한 후 잠그며 기존 다크 팔레트를 가져오지 않는다.

현재 반입 팩은 Ninja Adventure CC0의 신규 CharacterAnimated/NinjaGreen과 같은 팩의 환경이다. Tiny Swords CC0 구버전은 Hit 결손으로 채택하지 않았다. 영웅/적은 같은 신규 원본에 Katana/Axe와 진영 tint를 적용하며 별도 몬스터를 확보했다고 표현하지 않는다. 원본 프레임은 검수했지만 Unity 화면·사용자 시각 승인은 미완료다. 여러 작가의 픽셀 크기/외곽선/시점을 무작정 섞지 않는다. Game UI Database/Pinterest/Dribbble 화면은 배치 참고용이지 추출해 게임에 넣을 자산이 아니다.

필수 클립: idle, walk, attack 또는 cast, hit, death. 첫 영웅·적의 클립에서 프레임 순서, 반복, 기본 방향, 발 pivot, 손/무기 위치, impact를 함께 검수한다. 프레임 개수보다 실제 자세 변화와 타격의 일치가 중요하다.

기존 Git 이미지 복원, 색변경 재활용, 옛 그림을 생성 참고로 제공, 막대형 SVG 대체, 정지 원화 흔들기를 완성으로 보고하는 행위를 금지한다. 텍스트 회고에도 거절된 이미지를 복사하지 않는다.
