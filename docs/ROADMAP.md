## 장기 콘텐츠: 삭제하지 않는 기획

**도감:** 몬스터·아이템 최초 발견과 누적 수집을 구분한다. 도감 보상은 일회성 수령 ID로 중복 지급을 막고, 초기에 과도한 영구 능력치로 격차를 만들지 않는다.

**환생:** 리셋 대상과 영구 보존 대상, 보상 산식, 사용자 확인을 별도 사양화한다. MU/바람의나라의 이름만 빌려 초기 수치를 단정하지 않는다. 실제 초기화는 새 저장 트랜잭션/복구 검수 뒤에만 구현한다.

**펫:** 따라오기·대기·공격·지원의 읽히는 동작이 먼저다. 장비처럼 숫자만 존재하는 펫이나 이름만 표시되는 소환 결과를 만들지 않는다. 첫 펫1종을 끝낸 뒤 확장한다.

**무료 재화 소환:** 확률표·중복 조각·천장·재화 차감·결과 영수증·저장 실패를 하나의 거래 흐름으로 검증한다. 유료 가챠와는 별도 단계다.

**외형 아바타:** 전투 능력과 외형 소유권을 분리한다. 현재 몸/무기 일체형 제작에서 외형 교체 요구가 생기면 별도의 방향/손 기준점/레이어 작업을 먼저 한다.

**시즌 / 래더 / 스탠다드:** 시즌 시작 자산, 시즌 전용 보상, 시즌 종료 후 이전, 가방 초과, 중복 이전을 정의한다. 한정 외형 아이템의 계정 소유권을 시즌 종료와 함께 지우지 않는다. 검증 가능한 순위는 서버 권한 설계가 필요하다. 최초 로컬 시즌 실험과 상업 온라인 시즌 운영을 같은 완료로 취급하지 않는다.

**오프라인 보상:** 최대 정산 구간, 시각 조작, 중복 수령, 기존 전투 결과와의 경제 밸런스를 먼저 검증한다.

**결제/상점:** 거래 검증·환불·운영·정책 검토 뒤 선택한다. 초기 MVP의 필수 항목이 아니다.

## 성능

실제 아트/동작/보상/화면이 승인된 뒤 대표 장면으로 측정한다. 죽지 않는 캐릭터와 아무 효과도 없는 시험 장면의 결과를 제품 성능으로 대체하지 않는다. 긴 프레임을 임의 제거하거나 측정 중 매 프레임 전체 정렬을 하지 않는다.
