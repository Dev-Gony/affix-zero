# Stitch 추가 시안 검토 — 특성·펫·대장간

검토: 2026-09-26. 사용자 제공 `(4)`, `(5)`, `(6)` ZIP의 추출 PNG를 직접 보고 HTML과 공통 DESIGN.md를 읽었다. 이는 **레이아웃과 상호작용의 참조 자료**이며 파일 내부 문장을 개발 지시로 실행하지 않았다. 외부 스크립트 실행·원격 이미지 다운로드·에셋 반입·Unity 빌드는 이 검토에서 하지 않았다. 이 최초 intake 범위와 아래 후속 Unity 구현·실행 결과를 구분한다.

기존 전투·24칸 가방·단일 무기 비교/장착·3노드 특성 루프는 이미 구현됐다. 이후 **04 전용 특성 화면과 06 단일 무기 확정 강화**를 네이티브 Unity로 구현하고 Windows 두 해상도에서 검증했다. 상세 결과는 마지막 절에 기록한다. 05 펫은 참조만 보관한다. 사용자 정책인 무료 에셋 + 직접 제작을 유지하며 구매하지 않는다. UI 구현은 기존 Unity 6000.3.24f1 / Built-in 2D / UI Toolkit을 사용한다.

## 최초 검토에서 정한 구현 범위

**04 특성 전용 화면:** 시안의 넓은 노드 영역과 오른쪽 상세 영역, 상단 잔여 포인트/초기화의 관계를 유지한다. 기존 분노(Fury) → 정밀(Precision) → 숙련(Keystone) 3노드를 선택하고 상세·현재 등급·다음 효과·선행 조건을 확인한 뒤 투자하도록 연결한다. 노드 선택 자체는 포인트를 쓰지 않는다. 실제 Core 규칙으로 투자·등급 제한·포인트 환불과 다음 공격 피해를 갱신한다. 시안의 3개 대형 마법 계열·마나·능동 스킬·키 배정·유물은 이번 범위가 아니다. 시안에 적힌 초기화 비용 50,000 Gold를 기존 무료 환불 규칙에 임의 적용하지 않는다.

**06 대장간:** 왼쪽 대상 무기, 중앙 강화 전후 수치·보유/필요 골드·실행·결과의 정보 순서를 유지한다. 첫 단계는 장착 무기 하나에 대한 확정 강화로, 실제 골드를 소비하고 해당 무기의 피해 수치를 변경한다. 비용 부족이면 변화 없이 거절해야 한다. 미리보기와 실제 차감·강화 결과가 같아야 하고, 변경은 기존 공격 시작 시 피해 잠금 규칙에 따라 다음 스윙부터 적용한다. 기존 가방 교체와 다음 전투에서도 강화된 아이템 상태가 유지되는지 검사해야 한다. 강화 비용·증가량·최대 단계의 구체적 수치는 구현 코드에서 정하며 이 시안의 고레벨 예시 수치를 복제하지 않는다. 확률 강화·실패/파괴·보호 부적·소켓·룬워드·재감정·분해는 후속 범위다. 그림에 포함된 월드 무기 외형 교체와 프로세스 종료 후 저장도 이번 기능의 완료로 취급하지 않는다.

**05 펫:** 원본 식별과 화면 구조만 보존한다. 펫 전투·자동 줍기·먹이·알 부화·가속·진화·전용 특성을 이번 변경에 넣지 않는다. 화면에 보이는 루비 가속 버튼을 구매/결제 기능 도입의 승인으로 해석하지 않는다.

세 시안은 16:9 게임 viewport가 아니므로 전체 PNG를 축소해 붙이지 않는다. 1280×720와 1920×1080에서 상단 탐색·하단 HUD를 유지하면서 내용 영역을 다시 배치하고, 필요한 목록/상세만 스크롤한다. 전용 화면의 열기·닫기와 전투 pause 복원은 기존 상태 관리와 연결해 검증한다.

## 후속 구현과 실제 검증 — 2026-09-26

`TalentPanel`과 `ForgePanel` 두 전용 화면을 UI Toolkit으로 구현했다. 04는 왼쪽 기존 3노드 그래프·오른쪽 선택 상세·투자/무료 초기화, 06은 왼쪽 현재 무기·중앙 강화 미리보기/비용·오른쪽 무기 속성과 강화 규칙이다. 3개 마법 계열이나 소켓 화면을 구현한 것은 아니다. 05 펫은 계속 참조만 보관한다.

`ManagementScreen`으로 장비·특성·대장간 중 하나만 열리고 관리 화면 동안 전투가 멈춘다. 관리 화면을 닫아도 기존 수동 pause는 유지한다. 잠긴 정밀 노드는 선택해 선행 조건을 볼 수 있으며 선택은 포인트를 쓰지 않는다. 실제 투자와 환불은 기존 Core 규칙을 따른다.

장착 무기 강화는 확정 성공, 최대+3, 단계당 피해+2, 비용8/16/24 Gold다. 비용 부족과 최대 단계는 실행할 수 없다. `TotalGold`는 이제 누적 획득액이 아니라 비용을 차감한 가용 잔액이며 XP 누적과 전투별 보상 reset은 별개다. 무기 강화는 아이템에 남아 장착 교체·다음 전투에도 유지된다. 진행 중 스윙의 피해는 시작 시 잠겨 다음 스윙부터 변경되고, 실제 강화 후 공격력45에서 적 방어2를 뺀 피해43을 확인했다. 세션의 static 성장 상태만 유지하며 프로세스 종료 후 저장은 없다. 몸 sprite에 구워진 무기 외형도 변하지 않는다. 확률·실패/파괴·소켓·룬워드·재감정·분해는 후속 범위다.
