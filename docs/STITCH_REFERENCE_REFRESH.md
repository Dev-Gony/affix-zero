# Stitch 07–12 기준 네이티브 UI 재구성

기준일: 2026-09-26. 사용자가 다시 제공한 07–12 시안의 화면 구성에 맞춰 현재 Unity UI Toolkit 화면을 수정했다. 엔진은 Unity 6000.3.24f1, Built-in 2D를 유지한다. 이 문서는 **소스 변경과 원본 비교 기록**이다. 이번 수정본의 Unity 실행·실제 화면 검증은 아래 별도 상태를 따른다.

## 원본 식별과 이전 시안 비교

[확장 manifest](assets/stitch-reference-expansion-07-12.json)에 여섯 화면의 이름, 원본 intake의 ZIP SHA-256, 화면 크기, 추출 파일별 크기·전체 SHA-256을 기록했다. `Build/Reference/Stitch/intake-07-12.json`의 메타데이터를 보존하고, 실제 추출된 `screen.png`, `code.html`, `DESIGN.md` 18개의 해시와 길이를 다시 계산해 일치 여부를 확인했다. 비교 대상은 기존 00–06 폴더의 같은 이름 파일이다.

| 신규 참조 | 화면 | 기존 추출 파일과의 관계 |
|---|---|---|
| 07 | 영웅 선택 | 00의 PNG·HTML·DESIGN과 모두 SHA-256 일치 |
| 08 | 던전 전투 | HTML은 01과 일치. PNG는 00–06 어느 PNG와도 해시가 같지 않음. DESIGN은 공통 문서와 일치 |
| 09 | 타운 거점 | 02의 PNG·HTML·DESIGN과 모두 일치 |
| 10 | 장비·특성 관리 | 03의 PNG·HTML·DESIGN과 모두 일치 |
| 11 | 대장간 강화 | 06의 PNG·HTML·DESIGN과 모두 일치 |
| 12 | 특성 트리 | 04의 PNG·HTML·DESIGN과 모두 일치 |

모든 DESIGN.md는 공통 SHA-256을 갖는다. 08 PNG는 467,786바이트이며 01 PNG는 467,774바이트다. **이는 PNG 파일 내용이 다르다는 확인이며, 배치나 픽셀이 수정됐다는 결론은 아니다.** 이번 비교에서는 PNG를 디코딩한 픽셀 동등성 검사를 하지 않았다. ZIP 해시가 다르다는 이유로 새로운 디자인이라고 판단하지 않는다. 05 펫 화면과 일치하는 신규 화면은 이번 여섯 묶음에 없다.

참조 원본은 ignored `Build/Reference/Stitch`에 유지한다. HTML은 외부 스크립트·폰트·이미지 URL을 포함한 디자인 자료로 읽었으며 실행하거나 원격 이미지를 게임 에셋으로 반입하지 않았다.

## 16:9 적용 원칙

전투 원본은 1600×1335, 장비 원본은 1362×1600처럼 일반적인 PC 16:9보다 세로로 길다. 원본 전체를 작은 화면으로 축소하지 않고, 상단 탐색·하단 전투 HUD·좌측 장비와 가방·우측 특성과 비교의 관계를 유지해 재배치한다. 네이티브 화면의 설계 좌표는 1280×720이고 실제 확인 대상은 1280×720 및 1920×1080이다.

색은 어두운 바탕 `#0c0e11`, 패널 `#1a1c1f`, 내부 구분 `#282a2d`, 분홍 강조 `#ffb3b4`, 골드 `#e9c349`, 파랑 `#97cbff`, 붉은 선택점 `#c41e3a`를 중심으로 정리했다. 실제 캐릭터·무기·특성 아이콘과 네이티브 라벨을 사용한다. 원본 속 레벨·DPS·치명타·마나·소켓·가짜 장비 슬롯을 현재 게임 수치로 복제하지 않는다.

## 변경한 화면 구조

### 전투 공통 HUD — 08 기준

상단 탐색 띠는 높이 56, 하단 공통 HUD는 높이 130으로 구성한다. 좌우 구체는 각각 84 크기다. 좌측은 실제 HP에 연결한다. 오른쪽 MP는 미지원 상태를 `—`와 빈 수위로 표시하며 동작하는 마나 시스템처럼 채우지 않는다.

중앙에는 실제 기본 자동공격 아이콘·공격 진행을 두고, 옆 여섯 칸은 아직 할당되지 않은 스킬 자리로 표시한다. 빈 칸은 동작하는 스킬 버튼이 아니며 툴팁도 미지원 상태를 설명한다. 누적 XP에는 임의 레벨이나 다음 레벨 기준치를 붙이지 않는다.

상단 구역·대상 정보, 좌측 실제 처치 수와 세션 보상, 우측 실제 던전 미니맵을 분리한다. 자동사냥 시작/정지, 관리 화면 이동, 저장 상태와 실패 시 재시도는 기존 기능에 연결한다. 관리 화면을 연 동안 사냥이 계속되는 규칙도 유지한다.

### 장비·특성 관리 — 10 기준

`EquipmentPanel`의 영역을 `(16,64,1248,516)`으로 변경했다. 상단에 별도 관리 헤더와 던전 복귀 버튼을 두고, 왼쪽 상단을 장착 무기 카드 / 확대된 실제 영웅 / 능력치 표의 세 영역으로 재구성했다. 단일 장착 무기 카드에는 현재 이름·아이콘·무기 피해·어픽스·강화 설명만 표시한다. 현재 모델에 없는 추가 장착 슬롯이나 희귀도 수치를 만들지 않는다.

왼쪽 아래 가방은 기존 24칸을 8×3으로 유지한다. 아이콘, 이름, 선택 배경과 테두리를 구분하고 긴 이름·설명은 툴팁으로 확인할 수 있다. 오른쪽 위에는 분노 → 정밀 → 숙련의 실제 세 노드와 잔여 포인트·선행 조건·초기화를 배치한다.

오른쪽 아래 비교창은 선택 아이콘과 아이템명, 크게 표시한 실제 무기 피해, 현재 총공격력 → 장착 후 총공격력, 어픽스 설명, 하단 교체/버리기 동작으로 나눈다. 무기 피해를 DPS로 표기하지 않는다. 버리기 확인 절차와 기존 named control/API는 유지했다. 능력치 라벨에는 `equipment-damage-value` 이름을 추가했다.

### 특성·대장간 — 12·11 기준

특성 전용 화면은 상단 포인트 요약, 왼쪽 세 노드 연결, 오른쪽 선택 효과와 투자 버튼, 하단 실제 공격력 요약으로 구성한다. 여러 직업이나 아직 없는 가지를 화면만 채우려고 추가하지 않는다.

대장간은 왼쪽 현재 장착 무기 선택, 중앙 큰 무기 미리보기와 강화 전후 피해·공격력, 오른쪽 실제 속성·골드 잔액·강화 규칙으로 구분한다. 기존 확정 강화 +1~+3, 단계당 피해 +2, 비용 8/16/24골드를 유지한다. 소켓·확률 실패·재련·추가 재료는 구현하지 않는다.

## 이후 우선순위

UI 수정본 실행 확인 다음에는 자동사냥의 사망·가방 포화·저장 실패 복구와 20분 무조작 검증을 우선한다. 그 뒤 실제 효과가 있는 기본 스킬과 반복 전리품·빌드 선택 루프를 보강한다. 영웅 선택·타운·펫·가챠 등의 화면 수를 늘려 자동 던전과 성장 루프 검증을 대신하지 않는다. 수행하지 않은 장시간 검사를 완료로 기록하지 않는다.
