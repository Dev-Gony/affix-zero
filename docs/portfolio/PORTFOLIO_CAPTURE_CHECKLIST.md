## For each portfolio slide/page

Record:
- Problem
- Why it mattered to the player
- Reference researched
- Decision
- Implementation
- Failure or trade-off
- Verification
- Before screenshot
- After screenshot
- Commit/PR reference

## Do not frame the project as

"I copied Hero Siege and Survivor.io."

Frame it as:

"I decomposed two proven interaction models, selected the parts that solved different problems, and combined them around an unattended auto-hunting loop with explicit persistence and inventory-safety rules."
