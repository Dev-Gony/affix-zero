# 자동사냥 MVP — 현재 우선 작업

기준: 2026-09-26 사용자의 방향 재확인. **Hero Siege 오마주 RPG 시스템 + 캐릭터가 스스로 던전을 도는 방치형 자동사냥**이다. 이 문서는 다음 작업의 구현 기준이며 완료 보고서가 아니다.

## 현재 상태와 우선순위 교정

검증된 기능은 1대1 자동 접근/타격, 장비·특성·강화와 네이티브 관리 화면이다. 현재 MeleeActor는 지정된 적에게 직접 접근하고, FirstEncounter는 수동 회수와 다음 전투 버튼으로 같은 씬을 재시작한다. 이동 가능한 던전 경로, 자율 탐색/대상 재선정, 자동 회수/다음 구간, 반복 드랍, 디스크 저장이 없다. 105개 코어 검사와 기존 Windows PASS는 이 제한된 범위의 근거다. 방치형 MVP 완료나 자동 던전 순환 성공을 뜻하지 않는다.

기존 인수인계의 다음 작업 '영웅 선택 → 타운'을 내린다. UI 시안은 유지하되 화면 확장 대신 실제 자동 던전 순환부터 구현한다. 원작과 같은 모든 옵션을 첫 MVP에 한꺼번에 넣는 일정은 잡지 않는다. 장비·특성·강화·펫 등은 제품 방향으로 유지하고 플레이 가능한 핵심부터 순차적으로 확장한다.

## 첫 전달물의 범위

- 영웅 1종, 이동 가능한 소규모 던전 1종과 연결 구간. 맵 표시와 실제 장애물/통행 경계가 일치해야 한다.
- 시작 한 번으로 탐색 → 도달 가능한 적 선택 → 이동 → 자동 공격/기본 스킬 → 전리품 자동 회수 → 다음 구간 → 반복 사냥. 매번 '다음 전투'를 요구하지 않는다.
- 적 사망/도달 불가/길 막힘 시 다른 대상이나 경로를 선택하고 영원히 벽을 향해 걷지 않는다. 사망 시 상태와 재도전 규칙을 명확히 표시한다.
- 반복 드랍과 제한된 어픽스/장비 선택, 현재 특성·강화 연결. 더 나은 빌드가 사냥 시간·생존·획득 결과에 반영돼야 한다. 장비 자동 교체를 강요하지 않는다.
- 관리 화면을 열어도 자동사냥 유지. 별도 수동 정지/재개 제공. 가방 포화 시 무단 아이템 삭제·자동 분해 없이 명확한 보존/중단 처리.
- 로컬 저장/불러오기: 장비·특성·강화·경험치·골드의 영속성, 재실행 시 중복 보상 방지, 저장 실패 표시. 오프라인 누적 보상은 별도 후속 기능.
- Windows 실행 파일과 실제 검증 기록. 설치된 Unity 버전과 Built-in 2D 유지.

## 전달 순서와 완료 기준

| 순서 | 전달할 결과 | 통과 기준 |
|---|---|---|
| 1 — 자동 던전 플레이 빌드 | 현재 1대1 씬을 넘어 탐색·여러 대상·회수·다음 구간·재도전 연결 | 조작 없이 던전 순환 3회, 길 막힘/목표 사망 처리, 중복 타격/보상 없음 |
| 2 — 성장·저장 연결 | 반복 전리품과 빌드 변화, 관리 중 사냥, 종료 후 성장 복원 | 실제 피해/사냥 결과 변화, 저장 후 재실행 상태 일치, 포화·사망 복구 |
| 3 — MVP 실행 검수 | 첫 두 단계를 묶은 배포 가능한 Windows 빌드 | 20분 무조작 연속 실행과 두 해상도 UI 확인, 수동 시작/정지·메뉴 조작 확인, 치명적 예외 없음 |

위 시간/횟수는 예정된 합격 기준이며 아직 수행하지 않았다. 1단계의 경로·맵·적 전환 통합을 실제 실행하기 전에는 달력 기준 출시일을 확정하지 않는다. 검사 숫자나 UI 수로 전체 완성률을 만들지 않는다. 다음 사용자 전달은 메뉴 추가 데모보다 자동 던전 플레이를 우선한다.

펫·다중 클래스·대형 스킬 트리·소켓/재련·타운 전체·시즌/가챠는 첫 MVP 이후다. 사용자 Stitch 시안 7개와 라이선스 검수, 이전 코드/아트 복원 금지, 기존 사용자 파일 보호 규칙은 유지한다.
