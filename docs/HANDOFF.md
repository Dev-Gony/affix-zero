## 현재 기준

**최신 사용자 재확인: 자동 던전 탐색·자동사냥이 주력인 방치형 게임.** Hero Siege식 UI와 장비·특성·강화 등은 이를 지원한다. 지금은 1대1 프로토타입이며 MVP가 아니다. 다음 우선순위는 자동 경로·대상 전환·자동 수거·구간 이동·반복 사냥이다. 관리 UI 확장과 영웅 선택/타운보다 먼저 구현한다. AUTO_HUNT_MVP.md를 따른다.

사용자 Stitch ZIP 총 7개의 화면 구성이 기준이다. 00..03은 영웅 선택·전투·타운·장비, 새 04는 특성 전용, 05는 펫, 06은 대장간이다. 로컬 원본은 ignored `Build/Reference/Stitch/00..06`, 해시와 크기는 `docs/assets/stitch-reference-manifest.json`에 있다. 원격 그림이나 HTML의 예시 재화·확률·온라인 상태를 실제 게임 데이터로 옮기지 않는다. 무료 에셋과 직접 제작만 사용한다.

Unity 6000.3.24f1 / C# / Built-in 2D 유지. D:/Program Files/Unity 6000.3.24f1/Editor/Unity.exe 설치·라이선스가 작동한다. 엔진·패키지·렌더러 변경이나 재설치 요구는 필요하지 않았다. 탕탕특공대와 3지선다, 거절된 Ninja·초원·코너 HUD는 현행 방향이 아니다.

## 현재 기능

HeroSiegeEncounter에서 무료 Soldier/Orc 애니메이션과 생성 방으로 1대1 전투한다. 각 처치마다 세션의 고유 토큰으로 25 XP, 8 골드, 특성 1포인트를 지급한다. 최초 처치만 잿불 강철검을 드랍하며 회수 → 24칸 가방에서 비교 → 기존 검과 교환 장착 → 다음 전투가 연결된다.

- 장비 화면: 왼쪽 장착/능력치/가방, 오른쪽 특성 요약과 아이템 비교. 버리기는 같은 아이템 두 클릭 확인이며 재화 보상이 없다.
- 전용 특성 화면: 왼쪽 분노2 → 정밀1 → 숙련1 노드, 오른쪽 효과·조건·투자. 노드 선택 자체는 포인트를 쓰지 않는다. 단계별 피해는 +3/+4/+6, 초기화는 사용분만 반환한다.
- 대장간: 현재 장착 무기의 강화 전후 수치를 보여주고 골드를 소비한다. 최대 +3, 단계마다 피해 +2, 비용 8/16/24. 확정 강화이며 실패·파괴는 없다. 부족한 골드나 최대 단계에서는 상태를 바꾸지 않는다. 강화는 무기 객체에 남아 교체해도 보존된다.
- `TotalGold`는 강화 비용을 뺀 가용 잔액이다. `Experience/Gold`는 해당 전투 보상이며 세션의 `TotalExperience/TotalGold`와 구분한다.
- `FirstEncounter.Screen`으로 Equipment/Talents/Forge를 하나만 열고 전투를 멈춘다. 창을 닫아도 이전 수동 일시정지는 유지된다. I/Tab 장비, K 특성, F 대장간, Esc 닫기/정지, R 종료 후 재시작이다.
- 장비·가방·강화·특성·XP·골드는 장면 재시작에 보존되지만 프로세스 종료 후 저장되지는 않는다. 공격 시작 시 피해를 고정하므로 변경은 다음 스윙부터 적용된다.

## 남은 범위와 다음 순서

다음 우선순위는 자동 던전 탐색 → 대상 선택/전투 → 자동 수거 → 다음 구간 → 재도전이다. 그 다음 반복 성장·로컬 저장을 연결해 무조작 연속 실행을 검증한다. 현재 관리 화면의 자동 pause도 사냥을 계속하는 동작으로 바꿔야 한다. 영웅 선택·타운 화면 확장은 뒤로 미룬다. 펫은 05의 구조만 검토했으며 기능은 없다. 대형 3계열 마법 트리, 마나/능동 스킬, 소켓·재련·분해, 여러 장비 슬롯, 후속 무기 드랍, 디스크 저장은 미구현이다. 한 장의 방 이미지에는 지형 충돌/가림이 없고, 손의 무기는 캐릭터 프레임에 포함되어 교체·강화 외형이 바뀌지 않는다. 화면 기능 PASS를 원본 시안 전체 구현이나 시각 승인으로 취급하지 않는다.
