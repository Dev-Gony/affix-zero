# ART-RESET-01: 기존 이미지 전면 삭제

결정일: 2026-09-26 KST
삭제 전 기준: 46ad2db3538734d3aed48a119856f32862f7c164
브랜치: chore/r0-preservation
사용자 명시 요청: 현재 사용하는 모든 이미지 삭제. 다크한 기존 분위기 폐기. 플레이 스타일/아이템/스킬 등 게임 규칙만 유지하고 외부의 검증된 2D RPG 리소스로 다시 선정.

## 삭제

- 루트 assets/ 전체: AI 생성 배경·직업/적/장비/아이템 아틀라스, 이전 CC0 개별 이미지, 관련 import 파일과 이전 asset 안내.
- experiments/e0-godot/assets/ 전체: 전사/근접/원거리의 기존 SVG 포즈와 source 안내.
- design-system/ 전체: 기존 다크 팔레트 및 화면 방향.
- 현재 작업 트리에 옛 이미지를 archive/reference/backup 등의 다른 이름으로 복사하지 않는다.
- 삭제 검사는 확장자뿐 아니라 삭제 전 모든 이미지의 Git blob SHA가 현재 파일에 재등장하는지도 검사한다.

## 보존

scripts/, resources/, scenes/, tests/ 및 E0/V0의 기존 규칙 소스는 기존 파일 바이트를 유지한다. 아이템/스킬/어픽스/드랍·경험치 계산/전투/저장 규칙을 미리 파괴하지 않는다. 기존 렌더와 결합된 파일은 .gdignore 아래 비활성으로 보존하며 재연결할 때 규칙만 추출한다. 해당 소스에 남은 과거 팔레트나 그림 복원 코드는 새 디자인의 기준이 아니다.

실제 Windows 저장 데이터, 기존 stash, main과 다른 브랜치, Git 과거 커밋은 건드리지 않는다. '삭제 완료' 범위는 이 개발 브랜치의 최신 작업 트리다. 사용자 PC에 반영하려면 이 브랜치를 동기화해야 한다. 과거 커밋/다른 worktree까지 지운 것으로 보고하지 않는다.

## 실행 처리

이미지만 지우고 preload 에러가 나는 상태로 넘기지 않는다. root와 E0 프로젝트 기본 실행을 이미지 없는 교체 상태 안내로 바꾼다. 자동 로드/저장 접근은 없다. 옛 이미지 의존 렌더 테스트는 비활성 이력으로 이동한다. 변경 후 audit는 삭제와 소스 보존을 검사할 뿐, 전투 게임 완성이나 신규 아트 승인으로 표시하지 않는다.

## 기존 판단 정정

부분 벤치마크 스크린샷은 최종 성능 판정 근거가 아니다. 이전 C03은 측정 중 매 프레임 표본 정렬과 1초 이상 프레임 제외 등 검토할 지점이 있어 그대로 출시 성능 기준으로 재사용하지 않는다. 이번에는 아트 제거만 수행하며 해당 측정 코드를 수정해 검증했다고 주장하지 않는다.

## 금지

기존 이미지를 다시 crop/recolor/reference로 사용, 옛 스크린샷 복원, 정지 원화 흔들기를 애니메이션으로 명명, 저품질 막대형 SVG 대체 제작, 무료 리소스의 공개 재배포 권한 추정, smoke test만으로 게임 품질 PASS 판정.

## 검증

python3 tools/audit_art_reset.py

삭제 파일과 SHA, 유지된 코드/데이터 개수, 현재 이미지 수를 JSON 보고서로 출력한다. 새로운 외부 이미지 반입 전 현재 이미지 수는 0이어야 한다. 실제 실행 결과는 HANDOFF와 PR에서 별도로 기록한다.
