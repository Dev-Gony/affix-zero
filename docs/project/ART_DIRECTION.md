# AFFIX: ZERO 새 아트 방향 v1

상태: 디자인 제안/리소스 선정 기준. 신규 게임 화면 완성 또는 사용자 최종 승인 아님.

## 한 문장

밝은 초원과 마을 주변에서 작은 영웅이 선명한 공격 동작으로 무리를 정리하고, 눈에 잘 들어오는 장비를 줍는 캐주얼 탑다운 액션 RPG.

## 가져갈 재미 / 가져오지 않을 외형

Hero Siege에서는 아이템 등급/어픽스/빌드와 파밍 깊이를, Survivor.io에서는 읽기 쉬운 자동 공격/수집/성장 선택의 흐름을 참고한다. 기존 게임 화면·상용 캐릭터·아이콘을 추출하지 않는다. 다크 판타지 분위기는 가져오지 않는다. 계정 성장, 아이템, 스킬, 환생, 펫, 외형, 도감, 시즌 로드맵은 유지하되 한 번에 구현하지 않는다.

## 새 시각 기준

| 요소 | 채택 방향 | 배제 |
| --- | --- | --- |
| 배경 | 낮 시간 초원, 연한 모래길, 푸른 물, 명확한 지형 경계 | 어두운 폐허, 검은 돌바닥, 피빛 균열, 붉은 안개 |
| 캐릭터 | 얼굴/몸/무기가 구별되는 둥근 실루엣, 선명한 팀 색 | 단일 그림 흔들기, 검만 떠다님, 막대형 대체 스프라이트 |
| 적 | 외곽선·크기·색으로 역할 구분, 공격 예고가 명확 | 얼굴/방향을 구분할 수 없는 뭉침, 지나친 피격 점멸 |
| UI | 밝은 종이/아이보리 패널, 청록 강조, 짙은 남색 본문 | 화면을 덮는 검정 패널과 개발 로그, 푸른 어두운 금속 테두리 |
| 보상 | 아이콘 실루엣 + 희귀도 테두리 + 등급 문구 | 색 하나만으로 등급 구분, 전투를 가리는 거대한 드랍 글자 |
| 카메라 | 탑다운/약한 3/4 시점 일관성 | 다른 해상도/시점/광원 패키지를 무계획 혼합 |

제안 UI 토큰: paper #FFF7E7, surface #FFFFFF, ink #243B53, accent #24A99A, gold #F3BD4F. 세계 팔레트는 최종 선택한 원본 팩을 유지하고 임의의 어두운 틴트를 덮지 않는다. 이 색들은 게임 전체 최종 팔레트가 아닌 UI 초안이다.

## 1차 시각 레퍼런스: Tiny Swords

https://pixelfrog-assets.itch.io/tiny-swords

넓은 녹색 지형/물 경계, 캐릭터와 무기 동작의 가독성, 전사/원거리 유닛의 구분, 종이·리본 기반 패널 구성이 새 방향과 가깝다. 이 판단은 팩 소개와 제작자 프리뷰에 대한 디자인 제안이다. 소스 ZIP의 실제 프레임/pivot 검수는 아직 하지 않았다. Tiny Swords의 RTS 경제/건설 시스템까지 가져오는 것이 아니다. 채택 대상은 그림 구성과 애니메이션 자료다.

## UI 최소 구성

전투 화면: 좌상단 HP/레벨, 상단 중앙 단계·경과 시간, 우상단 골드/일시정지, 하단 4~6개 스킬 상태만 표시한다. 개발 상태 enum, percentile, 노드 수는 기본 화면에서 숨긴다. 아이템 비교는 별도 패널을 열 때만 표시한다. 배경 위 텍스트는 불투명도가 충분한 패널에 올려 대비를 확보한다.

장비 화면: 7슬롯 장착 영역 + 인벤토리 격자 + 선택 장비 비교. 희귀도는 테두리와 한글 등급으로 중복 표시. 강화/잠금/장착 상태는 다른 작은 배지로 구분한다. 60칸 가방 데이터는 보존하되 한 화면에 모든 설명을 밀어 넣지 않는다.

## 첫 아트 검증 범위

영웅 1종, 적 1종, 야외 타일 1세트, 무기/방어구/반지 등 대표 아이템 6개, 기본 스킬 아이콘 3개만 확인한다. idle/walk/attack/hit/death가 실제로 있는지 각각 확인하고 부족한 동작은 미완료로 표시한다. 이미지 크기와 캐릭터 실제 몸체 크기를 구분한다. 공격 준비→충돌 프레임→회복을 재생해 손과 무기의 일관성을 확인한다.

검수 시 한 방의 밝은 필드에서 이동/공격/피격/드랍을 촬영한다. 최종 아트·애니메이션이 확인되기 전 40/150/300마리 벤치마크나 펫/시즌으로 확장하지 않는다.
