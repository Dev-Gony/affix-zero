# E0 엔진 선택과 실행 검증

2026-09-26 KST: SELECTED_FOR_MVP. 결정 원문은 ADR-001_ENGINE_ARCHITECTURE.md다.

## 선택 완료

Godot4.7.2-stable 일반판, 정적 타입 GDScript, Compatibility, 첫 검증 Windows. 기존 Godot4.3은 원본 재현용으로 유지한다. 새 전투 코어는 독립 프로젝트로 재작성한다. Unity/GameMaker 병렬 비교 제작은 하지 않는다.

선택은 요구/공식 기능/제작 복잡도에 근거한 기술 판단이다. 실측 결과를 주장하지 않는다. E0는 이제 선택한 엔진/구조의 동작 검증이며 선택 자체를 무기한 미루는 단계가 아니다. 향후 재현 가능한 엔진 결함, 필수 플랫폼/제작 도구 변경, 측정으로 확인된 엔진 병목이 있으면 ADR을 갱신한다.

## 안전 경계

사용자 버전/PC/저장 폴더는 채팅에서 확인됐고 실제 save.json도 수신했다. 백업 성공은 별도이며 마지막 시도는 실행 프로세스 검사에서 차단됐다. 원본에 쓰는 작업과 원본 프로젝트 변환은 금지 상태를 유지한다. 원본을 읽거나 쓰지 않는 독립 E0 코드 제작은 지금 진행 가능하다. 백업 확인을 이유로 엔진 결정/독립 구현을 다시 중단하지 않는다.

## 시험 범위

E0-C01: 독립 프로젝트와 실제 전사/근접 적 클립, 자동 접근, 공격 준비/발동/회복, 피격/사망.
E0-C02: 원거리 적, 실제 투사체 이동 구간 충돌, 드랍/회수 메모리 원장.
E0-C03: 같은 장면 40적 x1 기능/렌더/Windows export/성능 검증. 150/300적과 x2/x5는 별도 확장 시험이다.

배경은 작은 타일 방 하나다. 프레임 애니메이션은 몸+무기 일체형 첫 세트로 검증한다. 게임 표현을 생략한 점/도형 부하 데모로 타격감/시각 품질 PASS를 만들지 않는다. 펫/가챠/환생/시즌/상점은 첫 시험에 넣지 않는다.

## 기준 PC와 성능

사용자 보고서의 Ryzen7 5700X / GTX1050 / RAM31.9GiB / Windows10 Pro를 테스트 대상으로 사용한다. 출시 최소사양이나 통과 성능으로 단정하지 않는다. world640x360/window1280x720, 실제 동작과 효과를 포함한다.

워밍업10초/측정60초/3회 반복, 벽시계 기반 p50/p95/p99와 객체/효과 수, 메모리, 엔진패치/렌더러/vsync/빌드SHA를 기록한다. 40적 x1 p95 16.7ms/p99 33.3ms는 목표이지 측정 결과가 아니다. 시뮬레이션 배속과 측정 시간은 분리한다. 병목을 실제로 확인한 뒤 풀링/검색 빈도/공간 분할을 적용한다.

기능 세부 계약은 E0_ACCEPTANCE.md를 유지하되 해당 파일의 백업 선행조건과 '선택 전 양 엔진 비교 필수' 문장은 ADR-001로 대체한다. 실제 데이터 안전과 아트 라이선스/동작 승인은 완화하지 않는다.

## 현재 상태

엔진 선택/구조 설계: COMPLETE_DECISION.
