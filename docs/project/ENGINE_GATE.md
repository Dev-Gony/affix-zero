# E0 엔진 결정 게이트

상태: 요구 기준 제안 정리. 실제 장면/비교/성능 결과는 NOT_RUN. 원본 보존이 끝나기 전에 사용자 프로젝트를 변환하지 않는다.

## 변경하지 않는 방향

자동 목표 선택과 접근, 공격 준비 -> 발동 -> 회복, 실제 투사체 충돌, 피격/사망, 중복 없는 보상 이벤트를 검증한다. 수동 회피를 필수 조작으로 추가하지 않는다. 2D 다크 판타지 픽셀 표현과 Windows 첫 검증은 현재 제안이며 출시 플랫폼 확정 사실이 아니다.

첫 장면은 캐릭터 1종, 근접 적 1종, 원거리 적 1종, 작은 타일 공간, 근접 공격/투사체/드랍 각 1종이다. 펫·가챠·환생·시즌은 넣지 않는다. 실제 프레임 또는 승인된 리깅을 사용한다. 프레임 없이 도형으로 품질 통과를 대체하지 않는다.

## 동일 조건 비교

기본 품질은 1+2 전투 장면으로 확인한다. 부하 검증은 40적, 150/300적을 구분한다. x1/x2/x5는 별도 결과로 기록한다. 워밍업 10초, 측정 60초, 3회 반복이 제안 기준이다. 40적 x1의 p95 16.7ms 이하/p99 33.3ms 이하 목표는 달성 사실이 아니다.

동일 에셋·해상도·공격 계약·시드·효과 수·빌드 조건으로 비교한다. 사용자 Windows export와 CI 소프트웨어 렌더를 섞지 않는다. 코드 SHA·엔진 패치·렌더러·vsync·활성 객체 수·원시 로그를 함께 남긴다. 애니메이션/판정을 생략한 구현을 같은 부하로 인정하지 않는다.

## 결정 조건

Godot 지원 버전에서 원하는 표현/제작/성능/배포가 통과하면 유지 또는 버전 이전을 선택할 수 있다. 필수 아트/플랫폼 연동 부재, 검증된 엔진 병목, 반복적인 로컬 재현 실패가 있고 대안이 통과하면 Unity 등으로 전환한다. 원화 부족과 비효율적인 게임 코드를 엔진 한계로 오인하지 않는다. 반대로 기존 코드 보존을 이유로 잘못된 구조를 고수하지 않는다.

E0-02는 전체 게임 두 개를 병행 제작하지 않는 작은 검증이다. E0-03에서 선택 엔진·정확한 버전·실측 근거·남은 위험·필수 로컬 설치·데이터 이전/롤백 계획을 기록한다. 이후 MVP-A로 간다. 최종 아트가 없으면 BLOCKED_ASSET로 분리하고 사용자에게 필요한 에셋/선택을 구체적으로 요청한다.
