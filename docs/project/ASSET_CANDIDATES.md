## 사용자 제공 레퍼런스 사이트의 역할

Game UI Database: 출시 게임의 HUD/Inventory 정보 구조 참고용. 이번 도구에서는 robots 제한으로 사이트 본문을 열지 못했으므로 특정 화면을 조사 완료했다고 기록하지 않는다. 사용자 제안 필터 Mobile/RPG/Inventory/HUD를 다음 직접 확인 시 적용한다. 화면 캡처를 게임 에셋으로 추출하지 않는다.

Itch.io: 제작자별 팩/라이선스/실제 동작 검사. 사이트 전체가 단일 무료 라이선스가 아니다. Tiny Swords와 Ninja Adventure 제작자 페이지를 이번에 확인했다.

CraftPix: 카테고리와 라이선스 확인. 계정/소스 재배포 조건을 해결하기 전 원본 파일 반입 금지. 이번에는 리소스 다운로드/구매를 하지 않았다.

Pinterest/Dribbble: 배치·표현의 참고 후보. 이번 검색/접속으로 개별 작품을 충분히 검수하지 못했다. 채택된 리소스나 재배포 허가 출처로 쓰지 않는다. 남의 목업을 그대로 사용하지 않는다.

Kenney: CC0 라이선스가 명시된 팩을 필요 부위만 채택하는 후보. 이전에 쓴 Kenney Tiny Dungeon 자체는 삭제하며 새 후보와 혼동하지 않는다.

## 결정

새 목표 화면은 Tiny Swords 계열의 밝고 선명한 캐주얼 모험이다. 실제 반입 1순위는 제작자가 제공하는 Tiny Swords 구버전 CC0 파일 검수다. 구버전의 필요한 동작/범위가 부족하면 Ninja Adventure CC0를 별도의 대안으로 검사한다. 두 팩을 무계획 혼합하지 않는다. 현행 Tiny Swords 제한 라이선스와 CC0 구버전을 같은 파일로 취급하지 않는다.

상태: 페이지/라이선스 조사 완료. 원본 ZIP 다운로드와 프레임/피벗 검수는 미완료. 작업 컨테이너에서 GitHub DNS와 Kenney ZIP 다운로드가 실패했으므로 내려받았다고 주장하지 않는다. 사용자 ZIP 업로드 또는 승인된 다른 전달 경로로 실제 원본을 확보한 뒤 반입한다. 아직 구매/계정 접근/에셋 재배포를 수행하지 않았다.
